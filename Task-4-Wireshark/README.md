# Task 4 – Packet Analysis Using Wireshark

## Objective

To capture and analyze network traffic using Wireshark and identify DNS requests, HTTPS traffic, source IP addresses, destination IP addresses, and ports.

## Tool Used

Wireshark

## Procedure

1. Opened Wireshark.
2. Selected the active network interface.
3. Started packet capture.
4. Generated network traffic by visiting websites.
5. Stopped the packet capture.
6. Applied display filters to analyze specific traffic.
7. Identified DNS and HTTPS/TCP traffic.
8. Inspected source and destination IP addresses.
