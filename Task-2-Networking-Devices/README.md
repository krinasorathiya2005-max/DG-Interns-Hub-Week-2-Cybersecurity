# Task 2 – Networking Devices

## Objective

To understand the working, purpose, and real-world applications of important networking devices such as Router, Switch, and Firewall.

## 1. Router

A router is a networking device that connects different networks and forwards packets between them using IP addresses.

### Working

1. Receives a network packet.
2. Checks the destination IP address.
3. Checks its routing information.
4. Selects the appropriate route.
5. Forwards the packet toward its destination.

### Real-World Example

A home Wi-Fi router connects computers, smartphones, and other devices to the Internet.

## 2. Switch

A switch connects multiple devices within a Local Area Network (LAN).

### Working

A switch learns the MAC addresses of connected devices and forwards Ethernet frames to the appropriate port.

### Real-World Example

An office switch can connect computers, printers, servers, and access points within the same LAN.

## 3. Firewall

A firewall is a security device or software that monitors and controls network traffic based on predefined security rules.

### Working

A firewall can allow or block traffic based on IP addresses, ports, protocols, applications, and connection states.

### Real-World Example

A company firewall can allow required HTTPS traffic while blocking unauthorized incoming connections.

## Router vs Switch

| Feature | Router | Switch |
|---|---|---|
| Main Purpose | Connects different networks | Connects devices within a LAN |
| Address Used | IP Address | MAC Address |
| Typical OSI Layer | Layer 3 | Layer 2 |
| Main Function | Packet forwarding | Frame forwarding |
| Example | LAN to Internet | PCs in an office LAN |

## Security Importance

Routers, switches, and firewalls are important components of network infrastructure. Proper configuration and monitoring of these devices help maintain network availability, security, and controlled access.
